The ideas, fast

Why Git?

Git remembers every version of your project. Break something? Go back. Working with friends? Everyone’s changes fit together. Laptop dies? Your code is on GitHub.

Git vs GitHub

Git is the tool on your laptop. GitHub is the website that stores Git projects online so you can share them and team up.

Branches

A branch is a safe copy to experiment on. main stays clean. Like it? Merge it. Hate it? Delete it.

The loop you’ll repeat forever

edit files → git add . → git commit -m "msg" → git push

Add picks what goes in the snapshot. Commit saves it with a message. Push uploads it. git status is your best friend in between.

Put your site on the internet

GitHub Pages hosts websites for free. Tick each step as you go. Your progress stays in this browser.

Stuck? It happens to everyone

fatal: not a git repository

You’re in the wrong folder. Run pwd and ls , then cd into your project. Or run git init if it’s a new one.

Authentication failed / password not accepted

GitHub doesn’t take your account password for pushes. Run gh auth login , or create a personal access token (GitHub Settings → Developer settings) and paste it when Git asks for a password. Nothing shows while you paste. That’s normal.

nothing to commit, working tree clean

You haven’t changed anything since the last commit. Edit a file, save it, then git add . again.

Please tell me who you are

Git needs a name once: git config --global user.name "Your Name" and git config --global user.email "you@example.com" .

src refspec main does not match any

You pushed before your first commit. Run git add . and git commit -m "first commit" , then push.

Pages shows a 404

Give it a minute. Check Settings → Pages is set to main / root, and that your file is named exactly index.html .
